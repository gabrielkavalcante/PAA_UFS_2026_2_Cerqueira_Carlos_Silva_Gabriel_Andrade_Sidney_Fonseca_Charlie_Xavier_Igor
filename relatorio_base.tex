\section{Introdução e Contextualização}
O presente trabalho desenvolve-se no âmbito da disciplina de Projeto e Análise de Algoritmos (PAA), abordando o Tema 6, focado no processamento, busca e ordenação de notícias de fontes públicas. A relevância deste estudo reside na necessidade de manipular eficientemente grandes volumes de dados textuais não estruturados, aplicando rigor matemático e computacional para otimizar operações de recuperação de informação. O projeto visa integrar etapas de engenharia de dados, versionamento eficiente e implementação de algoritmos clássicos de ordenação e busca.

\section{Descrição do Corpus e Pré-processamento}
Para a realização dos experimentos, utilizou-se o Dataset de Notícias Folha/UOL extraído da plataforma Kaggle, composto por um volume bruto de aproximadamente 300 MB de dados textuais. Devido à natureza volumétrica do corpus e às diretrizes de versionamento do edital do projeto — que vedam o envio de arquivos de grande porte para o repositório remoto —, o conjunto de dados foi submetido a um pipeline de tratamento em Python. 

O script de pré-processamento (\texttt{preprocessamento.py}) executou as etapas de ingestão, limpeza de caracteres especiais, normalização de strings e estruturação. O arquivo final processado (\texttt{articles.csv}) foi hospedado em repositório externo seguro (Google Drive), garantindo o acesso padronizado de toda a equipe para as etapas subsequentes de análise algorítmica.

\section{Definição Formal do Problema}
O sistema recebe como entrada um corpus $C = \{d_1, d_2, \dots, d_N\}$, uma consulta $q$, e um valor inteiro $k \ge 1$.
A saída é uma lista $R = [r_1, r_2, \dots, r_m]$, com $0 \le m \le k$, ordenada de forma não crescente com base na função de relevância $f(d_i, q)$, que calcula a frequência absoluta dos termos de $q$ em $d_i$.

\section{Representação dos Dados e Estratégia de Chunking}
Os textos originais passam por normalização (minúsculas e remoção de pontuação). O particionamento (\textit{chunking}) é feito segmentando o texto em blocos de tamanho fixo, garantindo que o contexto seja granular o suficiente para as buscas.
