\section{Definição Formal do Problema}
O sistema recebe como entrada um corpus $C = \{d_1, d_2, \dots, d_N\}$, uma consulta $q$, e um valor inteiro $k \ge 1$.
A saída é uma lista $R = [r_1, r_2, \dots, r_m]$, com $0 \le m \le k$, ordenada de forma não crescente com base na função de relevância $f(d_i, q)$, que calcula a frequência absoluta dos termos de $q$ em $d_i$.

\section{Representação dos Dados e Estratégia de Chunking}
Os textos originais passam por normalização (minúsculas e remoção de pontuação). O particionamento (\textit{chunking}) é feito segmentando o texto em blocos de tamanho fixo, garantindo que o contexto seja granular o suficiente para as buscas.
